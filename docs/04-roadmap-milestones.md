# Product Roadmap and Milestones

**Status:** Proposed sequencing; calendar dates depend on team, funding, clinical review, and approvals.

| Phase | Target window from concept plan | Scope / exit evidence | Dependencies |
|---|---|---|---|
| 0. Discovery | Months 1–2 | User and clinician interviews; validated problem statement; MVP boundary | Ethics/privacy review for research; recruitment plan |
| 1. Design | Months 2–3 | Tested prototype, questionnaire, report draft, consent/privacy design | Clinical adviser; user feedback |
| 2. MVP build | Months 3–5 | Cycle/symptom tracking, history, report preview/export, reviewed education | Approved product and data specs; stack decision |
| 3. Usability pilot | Months 6–8 | Usability findings and improvement backlog; no diagnostic claims | Appropriate approvals, consent, support plan, security review |
| 4. Care linking | Months 8–10 | Facility directory or requests only after partner and data-sharing design | Verified facility data; agreements; privacy review |
| 5. Clinical validation | Months 10–14 | Protocol and evidence report for any proposed screening logic | Independent clinical/statistical input; ethics and regulatory review |
| 6. Scale | Month 14+ | Consider Android, telehealth, SMS/USSD, broader rollout | Funding, localization, accessibility, operations readiness |

## Priority order

1. Safety, privacy, accessible logging, and user-controlled report.
2. Reliability and usability of the core experience.
3. Localization and low-connectivity support.
4. Care-directory features with verified partners.
5. Any screening or research features only after explicit approval and validation.

No deadline is committed. Each phase needs a named owner, budget, acceptance criteria, and go/no-go review before work begins.
